# Dashboards

Role-specific front-end dashboards for the Legacy Real Estate Agency
platform. These are early prototypes (built with Lovable) used to validate
workflows per role ahead of/alongside the `apps/website` and `apps/core`
build-out.

| Role            | Dashboard                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| Director         | [Director's Dashboard](https://director-dashboard-land-management.lovable.app)                 |
| Branch Manager    | [Branch Manager Dashboard](https://branch-manager-legacy-real-estate.lovable.app)               |
| Landlord          | [Landlord Dashboard](https://real-estate-agency-legacy-real-estate.lovable.app)                 |
| Tenant            | [Tenant Dashboard](https://tenant-legacy-real-estate.lovable.app)                               |

> These are external Lovable-hosted prototypes, not part of this repo's
> build/deploy pipeline. Treat them as reference/UX material until (or
> unless) their functionality is absorbed into `apps/website` or `apps/core`.
